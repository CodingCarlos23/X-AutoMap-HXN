What this page documents: The deterministic AutoMap pipeline — blob detection across XRF element TIFFs using configurable CV/ML models, spatial union logic to find co-located features across elements, intensity filtering, and threshold-based phase matching against a material database. Runs without any AI API calls.

Detection Models

The detection method is set in the scan configuration JSON. Each model dispatches through the same blob detection API and returns normalized box + intensity data.

Simple

Global threshold → connected regions. Fast, no dependencies.

CV
StarDist

Star-convex polygon deep learning model. Great for round particles.

DL
Watershed

Distance-transform watershed. Separates touching blobs.

CV
Connected Components

Binary threshold + connected component labeling. Simple and reliable.

CV
Hough

Hough circle transform. Best for circular/spherical particles.

CV
Contours

OpenCV contour detection with area/circularity filtering.

CV
YOLO

Real-time object detection. Produces instance masks.

GPU preferred
Cellpose

Cell segmentation model. Produces pixel-level masks.

Step-by-Step Breakdown

  1. Load Scan Configuration

    A JSON config file specifies scan_id, elem_list (elements to analyze), detection_method, overlap_thresh (how much blobs must overlap to be counted as co-located), step_size, and optional groups for intensity filtering. All parameters flow into analyze_data_local() in analysis.py.

  2. Export Scan Parameters

    export_scan_params() fetches metadata from the data broker for the given scan_id and writes scan_params.json to results_dir. In offline mode this is skipped or reads from an existing file.

  3. Load Element TIFFs

    TIFFs are loaded from automap_{scan_id}/{elem}.tiff for offline mode, or fetched from the HXN data broker in live mode. Each TIFF is a 2D array of raw XRF counts for one element.

  4. Per-Element Blob Detection

    The selected model runs independently on each element TIFF and returns a list of detected blobs with position, size, and intensity. Results are merged into master_raw — a dict keyed by element name. Saved as MASTER_raw_detections.json.

  5. Phase Matching (on raw detections)

    run_phase_matching() in phase_matching.py computes per-blob elemental intensity ratios and compares them against a material database using configurable thresholds. Outputs phase_all_boxes.png, phase_matches.png, and phase_all_unions.png — green boxes matched, red boxes unmatched.

  6. Union / Co-location Logic

    find_union_blobs() in blobs/processing.py scans all element blobs spatially using overlap_thresh. Blobs from different elements that overlap sufficiently are grouped into a single union box spanning all contributing elements. The union box records which elements contributed and their measured intensity ratios.

  7. Cross-element Merge + Dedup

    _merge_cross_element_blobs() merges union boxes that share element membership and overlap. _dedup_formatted_blobs() removes duplicate detections. This cleans up over-segmentation from the initial union step.

  8. Intensity Filtering (optional)

    If use_intensity_filter: true in the config, unions with mean intensities below the configured per-element thresholds are removed. The pre-filter union set is saved as group_unions_{name}.json for visualization; the filtered set is saved as group_unions_{name}_intensity_filtered.json.

  9. Export Results

    Final outputs include group_unions_*.json (union boxes ready for fine scan queue), group_all_boxes_*.json (all individual blobs), and fine_scans_table_*.csv formatted for the beamline queue server. The Live Scan Viewer can then display phase detection results on the composite tile view.

Output Files

All outputs are written to results_dir (typically automap_{scan_id}/ in the working directory).

MASTER_raw_detections.json

All detected blobs across every element before union logic. Keyed by element name.

group_unions_{name}.json

Final union boxes after merging, dedup, and optional intensity filtering. Used for fine scan queue.

group_all_boxes_{name}.json

All individual blobs per element group, without union grouping. Used for visualization.

fine_scans_table_{name}.csv

Union boxes formatted as a fine scan table for the beamline queue server.

phase_all_boxes.png

OpenCV image with all raw detection boxes drawn.

phase_matches.png

OpenCV image showing only union boxes that matched a material phase.

phase_all_unions.png

OpenCV image: green = matched unions, red = unmatched unions.

automap_{id}_phase_*.png

Qt-rendered composite from the Live Scan Viewer with colored phase overlay boxes per tile.
