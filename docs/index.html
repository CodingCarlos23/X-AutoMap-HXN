AI Pipeline

VLM / LLM Workflow

Feature detection on XRF element TIFFs using Vision Language Models, followed by LLM-based co-location reasoning to identify where elements spatially overlap and suggest material phases.

  • OpenCV preprocessing (normalize, CLAHE, upscale)
  • Parallel VLM calls — one per element
  • Merge results into combined feature dict
  • LLM co-location analysis + phase suggestion
  • Output: feature JSON + composite PNGs

Deterministic Pipeline

AutoMap Pipeline

Deterministic blob detection across XRF element TIFFs using configurable CV models, followed by spatial union logic, intensity filtering, and threshold-based phase matching against a material database.

  • Load element TIFFs (offline or data broker)
  • Per-element blob detection (8 model choices)
  • Union / co-location across elements
  • Intensity filtering + cross-element merge
  • Phase matching → fine scan queue export
