AI Pipeline

VLM / LLM Workflow

Feature detection on XRF element TIFFs using Vision Language Models, followed by LLM-based co-location reasoning to identify where elements spatially overlap and suggest material phases.

  • OpenCV preprocessing (normalize, upscale, ★ colored circles or CLAHE)
  • Parallel VLM calls — one per element
  • Merge results into combined feature dict
  • LLM co-location analysis + phase suggestion
  • Output to the _vlm/ folder: feature JSON + composite PNGs

🔬
Deterministic Pipeline

AutoMap Pipeline

Deterministic blob detection across XRF element TIFFs using configurable CV models, followed by optional per-blob intensity filtering, spatial union logic, and threshold-based phase matching against a material library.

  • Load element TIFFs (offline or data broker)
  • Per-element blob detection (8 model choices)
  • Phase matching on raw detections
  • Optional per-blob intensity filter
  • Union / co-location → fine scan queue export

System Overview

Both pipelines read the same element TIFFs. The deterministic pipeline drives the fine scan queue today; the AI pipeline runs alongside it, and a side-by-side benchmark of the two is in progress (Benchmarks, beta).
