BETA · WORK IN PROGRESS

This page documents a benchmark that is still being built. The scripts in benchmarks/ are under active development and not yet committed, so names, variants and outputs may change. The current scores measure agreement between methods, not accuracy. They show where OpenCV, StarDist and the VLM variants agree, but not which one is right. Hand-labeled ground truth is the next step.

What this benchmark answers: is the VLM/LLM workflow an improvement over the deterministic OpenCV / StarDist pipeline (TODO #1), and which image preparation gives the VLM its best shot? Every method runs on the same sample TIFFs. Results are converted to one common format and compared at three levels: detection boxes, material regions, and an LLM pass that reconciles materials across methods.

Each AutoMap method is a real analyze_data_local() run. Each VLM variant goes through the same Feature Locator multi-element path the GUI uses.

How Scoring Works (current)

  1. Level 1: Box agreement

    For each element, every pair of methods is compared. Boxes are matched greedily by IoU (threshold match_iou, default 0.25). Reported as F1 = 2 × matched / (boxes in A + boxes in B) and mean IoU of the matches.

  2. Level 2: Material regions

    Each AutoMap method's phase_detections.json regions are matched against each VLM variant's co-location zones by overlap coefficient (≥ phase_match_overlap, default 0.5). Matched pairs also report element-set Jaccard similarity.

  3. Level 3: LLM reconciliation

    reconcile.py sends every method's material regions for a sample to an LLM. The LLM groups regions that describe the same particle or phase, even when methods name it differently or not at all. Which methods found or missed each group is then computed in code from region IDs, not from the LLM's counts.

  4. Cost tracking

    Every API call is logged with tokens, estimated USD cost, stop reason, truncation and parse status, so variant comparisons include what each one costs to run.

Running It

From the repo root. Full commands are in benchmarks/RUN_COMMANDS.txt.

eval "$(gpg --quiet --batch --yes --decrypt ~/.private_env.gpg)"   # load API key

pixi run python benchmarks/run_comparison.py benchmarks/configs/compare_default.json
pixi run python benchmarks/run_comparison.py benchmarks/configs/compare_default.json --no-vlm   # local only, no API cost

xdg-open benchmarks/runs/<timestamp>_test_samples/index.html
