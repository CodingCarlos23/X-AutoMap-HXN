HXN AutoMap — detection comparison benchmark
=============================================

Run from the repo root (~/Documents/github/X-AutoMap-HXN).

1) Make sure the API key is loaded in that terminal (Claude models):
     eval "$(gpg --quiet --batch --yes --decrypt ~/.private_env.gpg)"

2) Full run (OpenCV + StarDist + VLM raw/standard/circle/flower/car/car_standalone
   + OpenCV + LLM materials + LLM reconciliation):
     pixi run python benchmarks/run_comparison.py benchmarks/configs/compare_default.json

   Local methods only (no API calls, no cost):
     pixi run python benchmarks/run_comparison.py benchmarks/configs/compare_default.json --no-vlm

3) Open the report printed at the end, e.g.:
     xdg-open benchmarks/runs/<timestamp>_test_samples/index.html

Settings live in benchmarks/configs/compare_default.json
(VLM model, variants, prompt suffixes, StarDist params, OpenCV config path, match IoU).

Car Standalone vs OpenCV (+ LLM, + materials library) — 10-sample benchmark
---------------------------------------------------------------------------
Config: benchmarks/configs/car_vs_opencv_llm.json (StarDist off, OpenCV standard only,
VLM variant car_standalone only, OpenCV + LLM on, reconciliation on).
     pixi run python benchmarks/run_comparison.py benchmarks/configs/car_vs_opencv_llm.json

Focused report (reads results.json only — no API calls, rerun any time after editing the script):
     pixi run python benchmarks/car_vs_opencv_report.py benchmarks/runs/<timestamp>_car_vs_opencv_llm
     xdg-open benchmarks/runs/<timestamp>_car_vs_opencv_llm/car_vs_opencv.html

Rebuild every existing run's index.html after editing report.py (reads results.json only, no API calls):
     cd benchmarks && pixi run python -c "import json,pathlib,report; [report.write_report(json.loads((d/'results.json').read_text()), d/'index.html') for d in sorted(pathlib.Path('runs').iterdir()) if (d/'results.json').exists()]; report.write_runs_index(pathlib.Path('runs'))"

Level 3 (location agreement + LLM material judge, one call per sample) — runs automatically in new runs.
To add / redo it on an existing run (backs up results.json to results.before_level3.json, rebuilds its pages):
     pixi run python benchmarks/level3.py benchmarks/runs/<run>

OpenCV + Library + VLM cleanup (sample 1) — docs/opencv_vlm_cleanup.html
------------------------------------------------------------------------
Steps 1–2 (OpenCV + library) are free; step 3 is one VLM call per sample.
     pixi run python benchmarks/opencv_vlm_cleanup.py benchmarks/configs/opencv_vlm_cleanup.json
Free check first (no API call): add --dry-run (and --out-dir /tmp/ovc_dry to keep it out of runs/)
Redo only the VLM step on an existing run:
     pixi run python benchmarks/opencv_vlm_cleanup.py --cleanup-only benchmarks/runs/<run>
Rebuild the report (free):
     pixi run python benchmarks/opencv_vlm_cleanup_report.py benchmarks/runs/<run>
     xdg-open benchmarks/runs/<run>/opencv_vlm_cleanup.html
